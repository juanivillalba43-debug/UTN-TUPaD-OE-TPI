## Descripción del sistema

Módulo de software de inventario y planificación de producción para una planta piloto de Grupo Bimbo: registra existencias y movimientos de stock con número de lote, los vincula con las órdenes de producción y genera alertas de reposición cuando un insumo queda por debajo del stock mínimo.

Este repositorio aloja la documentación técnica del TPI, que se construyó en cuatro entregas.
